Soal

check Penalaran Umum #1

X memperbaiki radio yang rusak apabila tidak menonton pertandingan sepak bola di televisi.

Apabila memperbaiki kandang ayam di belakang rumah, X tidak mencari rumput di pekarangan.

Apabila X tidak memperbaiki radio yang rusak atau mencari rumput di pekarangan, manakah simpulan berikut yang BENAR?

Jawaban
A X menonton pertandingan sepak bola di televisi dan X tidak memperbaiki kandang ayam di belakang rumah.
B X tidak menonton pertandingan sepak bola di televisi atau X memperbaiki kandang ayam di belakang rumah.
C X tidak menonton pertandingan sepak bola di televisi dan X memperbaiki kandang ayam di belakang rumah.
D X tidak menonton pertandingan sepak bola di televisi, tetapi X memperbaiki kandang ayam di belakang rumah.
E X menonton pertandingan sepak bola di televisi atau X tidak memperbaiki kandang ayam di belakang rumah.

Pembahasan

Ubah "X tidak menonton TV apabila memperbaiki radio" menjadi "jika memperbaiki radio, maka tidak menonton TV". Premis kedua: "jika memperbaiki kandang ayam, maka tidak mencari rumput". Karena soal menyatakan "X tidak memperbaiki radio ATAU mencari rumput", ambil kontraposisi dari masing-masing implikasi: kontraposisi pertama adalah "jika menonton TV, maka tidak memperbaiki radio" dan kontraposisi kedua adalah "jika mencari rumput, maka tidak memperbaiki kandang ayam". Menggabungkan keduanya melalui disjungsi menghasilkan simpulan D: X tidak menonton TV, tetapi X memperbaiki kandang ayam.
